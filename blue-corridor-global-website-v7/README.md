# Blue Corridor Global Website

A responsive, multi-page static website built for Blue Corridor Global's executive alignment, corporate development, legacy advisory and institutional partnership positioning.

## Pages
- Home
- About
- Founder Profile
- Executive Advisory
- Alignment Lab
- Legacy Advisory
- CHAPTERS Project
- Speaking
- Contact

## Deployment
Upload the entire folder to Netlify, Vercel, Cloudflare Pages, GitHub Pages or any standard web host. The contact form includes Netlify form attributes and will work automatically when deployed through Netlify.

## Brand assets
The site uses the supplied Blue Corridor logo and one supplied founder portrait. No external font or JavaScript libraries are required.
